# Drink & Dance

Web estática en HTML, CSS y JavaScript, con las fotos incluidas.

## Subir a GitHub
1. Descomprimí este ZIP.
2. Creá un repositorio en GitHub.
3. En Add file → Upload files, subí el contenido de la carpeta drink-dance: index.html, styles.css, app.js, las páginas legales y la carpeta assets.
4. Confirmá con Commit changes.

Para GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

No requiere instalación ni compilación. El formulario abre WhatsApp con la consulta preparada.
